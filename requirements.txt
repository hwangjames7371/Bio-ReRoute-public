# ── 왜 `>=` 가 아니라 `==` 인가 ─────────────────────────────────
#
#   앞판은 전부 하한이었다(`gradio>=4.44`). 하한은 *"이것보다 새것이면
#   된다"* 는 주장인데 **우리는 그걸 시험한 적이 없다.** 시험한 것은
#   정확히 아래 한 조합이다. 배포지에서 다른 판이 깔리면 그건
#   **우리가 확인하지 않은 시스템**이다.
#
# ── 결함 86 — `rdkit-pypi` 는 우리가 쓴 물건이 아니었다 ──────────
#
#   앞판이 `rdkit-pypi>=2022.9.5` 를 요구했는데 `.venv` 에 있는 건
#   공식 `rdkit 2026.3.4` 다. **둘은 별개 배포판**이고, `rdkit-pypi` 는
#   2022.09.5 에서 멈춘 옛 커뮤니티 빌드다.
#
#   신선한 환경에서 이걸 깔면 **한 번도 안 써 본 2022년 RDKit** 위에서
#   S2(PAINS·Ro5)·hERG·DILI 가 돈다. 아무도 신선한 설치를 해 본 적이
#   없어서 넉 달 동안 안 보였다.
#
#   `deploycheck` 가 이제 이름을 대조한다.
